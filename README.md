Meesho Next — DICE Challenge 3.0 Prototype
Turning creator proof into more confident BPC commerce
🔗 Live Prototype: https://meesho-next-n14p-seven.vercel.app/
Overview
Meesho Next addresses two key BPC creator-commerce frictions:
Trial Stock
Brand-funded product trials that reduce creator product-access friction and enable authentic content creation.
Proof Match
Matches relevant creator proof to buyers based on need, suitability, language and context.

Core Flow
Creator: Discover → Trial → Create → Earn
Buyer: Discover → Matched Proof → Evaluate → Convert
Meesho: Creator × Product Fit → Proof → Buyer × Proof Match → Transaction → Learning
Experiment
	No Proof Match	Proof Match
No Trial Stock	Control	Proof Match
Trial Stock	Trial Stock	Combined


Primary KPI: Incremental NMV / ₹ Trial Stock Cost
Long-Term Vision
More trials → More proof → Better matching → More transactions → Better data
The long-term goal is to build a BPC Proof Graph that moves Meesho from creator-product matching to buyer-proof matching.
